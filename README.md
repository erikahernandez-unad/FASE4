# Sistema Integral de Gestión de Clientes, Servicios y Reservas

Proyecto desarrollado en *Python* bajo el paradigma de Programación Orientada a Objetos (POO) para el curso de *Programación (213023 - Grupo 645)* de la UNAD (Fase 4 – Prácticas Simuladas).

## Características del sistema
- *Gestión de Clientes y Servicios:* Registro, consulta y validación de datos.
- *Gestión de Reservas:* Creación, procesamiento, cancelación y control de disponibilidad.
- *Manejo de Excepciones y Logs:* Jerarquía de excepciones personalizadas y registro automático de eventos en archivo .log.
- *Simulación e Interfaz en Consola:* Menú interactivo y pruebas de operaciones válidas e inválidas.

## Ejecución del programa
Para ejecutar la aplicación desde la terminal:
```bash
python main.py
